UmmahGram — описание функций

UmmahGram — мессенджер на основе Telegram с приватностью и исламскими инструментами прямо в приложении.

Приватность

Режим призрака
Скрывает вашу активность от собеседников: не отправляет статус «в сети», не показывает «печатает…», не отмечает сообщения и истории как прочитанные, автоматически переводит аккаунт в оффлайн. Каждую функцию можно включать по отдельности или сразу все разом одним переключателем. Для отдельных чатов можно сделать исключение, чтобы там всё работало как обычно. Есть опция «отмечать прочитанным при ответе» — чтобы не выглядело подозрительно, если вы ответили в чате, где всё «непрочитано».

Шпион
Сохраняет удалённые собеседником сообщения (текст, помечается значком корзины прямо в чате) и историю правок — можно посмотреть все версии отредактированного сообщения. Не работает в секретных чатах, медиафайлы не сохраняются. Сохранённые данные можно очистить или экспортировать/импортировать файлом.

Ислам

Время намаза
Расчёт времени намазов по геолокации, с выбором метода расчёта Асра (по ханафитскому или шафиитскому мазхабу). Источник данных — онлайн (несколько международных методов расчёта: Karachi, ISNA, MWL, Умм-эль-Кура, Египетский, Кувейт, Катар, Сингапур, Турция, Россия, Moonsighting Worldwide) или офлайн-расчёт на устройстве. Уведомления по каждому намазу отдельно, с настраиваемым сдвигом по времени.

Кибла
Определение направления на Каабу — компас (по акселерометру и магнитометру устройства) и карта (на OpenStreetMap) с линией направления. Оба режима оформлены аккуратными карточками.

Коран
Полный текст сур с аудио начиткой — 12 чтецов на выбор (аль-Судайс, аль-Афаси, Абдул-Басит и другие). Поиск по названию/номеру суры, закладки на аятах, цветовая разметка таджвида с отдельным экраном-легендой, объясняющим каждое правило чтения.

Фикх (Шафии и Ханафи)

Справочник по двум мазхабам, разбитый на категории-плашки:
Шафии фикх: Тахарат, Намаз, Закят, Пост, Хадж и Умра, Погребальные обряды — по книгам имама ан-Навави и современному пособию Мустафы аль-Хина.
Ханафи фикх: Тахарат, Намаз, Закят, Пост, Хадж — по книге «Ханафитский фикх» Абдальхамида Тахмаза; там же отдельно отмечены расхождения с шафиитским мазхабом.
Каждая категория — отдельный экран с текстом, поиск ищет и по названиям категорий, и по содержимому.

Закят-калькулятор

Расчёт закята с учётом наличных, золота и серебра (отдельно инвестиционных и ювелирных, с выбором мазхаба — учитывать ли украшения), акций, криптовалюты, бизнес-активов, дебиторской задолженности, недвижимости, пенсионных накоплений, за вычетом долгов. Нисаб — по золоту (85 г), серебру (595 г) или по меньшему из двух, с актуальными ценами на металлы с сайта ЦБ РФ. Результат: сумма закята по ставке 2.5%.

Прочее
Обновления по воздуху
Приложение само проверяет наличие новой версии (и вручную, кнопкой в настройках), показывает изменения, скачивает и устанавливает APK прямо в приложении с индикатором прогресса.
